# IranianToken | ایرانیان توکن

اکوسیستم پروژه‌ها و ارزش‌های توکن‌محور.

## معماری اولیه
- `index.html` — صفحه اصلی
- `pages/projects.html` — فهرست پروژه‌ها
- `pages/project.html` — نمونه پنل اختصاصی پروژه
- `pages/ecosystem.html` — اکوسیستم
- `pages/how-it-works.html` — مسیر شکل‌گیری پروژه
- `pages/about.html` — درباره
- `pages/contact.html` — ارتباط
- `pages/404.html` — خطای ۴۰۴
- `assets/css` — سبک بصری
- `assets/js` — رفتارهای رابط
- `assets/fonts` — فونت‌های محلی
- `assets/images` — لوگو و گرافیک پایه

این نسخه، Foundation اولیه است و قبل از توسعه پنل‌های واقعی، مدل Project Engine و معماری داده باید تکمیل شوند.
